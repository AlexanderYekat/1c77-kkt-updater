# ERT roundtrip technical test

Консольный техтест ядра OLE/ERT **без UI**.

Сборка: открыть `ErtRoundtripTest.dpr` в Delphi IDE и Run.

Проверяет:

1. создание минимального `.ert` с `MD Programm text` + side-stream `SideMeta`;
2. запись **более длинного** модуля → повторное чтение;
3. запись **более короткого** модуля → нет хвоста старого текста;
4. SHA/size прочих OLE-потоков не изменились.

# Перенос хост=IP в kkt_hosts.txt

`KktHostsTest.dpr` — консольный тест `units/KktHosts.pas`. Сборка: открыть в Delphi IDE и Run,
в конце должно быть `ALL OK`.

Проверяет:

1. извлечение пар из старого хардкода `ОбеспечитьХостПрокси` (дубли и некорректный IP — пропуск;
   IP в комментариях / `Предупреждение` нового модуля — не пары);
2. создание `<ИБ>\kkt_hosts.txt` с заголовком, CP1251, CRLF (ERT в `ExtForms` и `ExtForms\Equip`);
3. повтор без дублей; IP, уже введённый пользователем, не перезаписывается;
4. ERT вне `ExtForms` → файл не пишется, предупреждение.

С параметрами `KktHostsTest.exe <модуль.txt> …` только печатает найденные пары для каждого TXT (UTF-8).
